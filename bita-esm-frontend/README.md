# BITA ESM Frontend

React-based admin dashboard for Enterprise Service Management.

## Technology Stack

- React 18+
- TypeScript 5.x
- TanStack Query
- React Router
- Zustand
- Tailwind CSS
- Shadcn/ui
- React Flow (route diagrams)

## Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Features

- Authentication pages (OTP-based login)
- Client management
- Service management
- Route management with visual diagrams
- LLM chat interface
- User management

## Environment Variables

Create a `.env.local` file:

```env
VITE_API_URL=http://localhost:8081/api/v1
```
